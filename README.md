# LaveroAdmin Extension Marketplace

A visual extension manager and marketplace for LaveroAdmin panel.

## Features

- Extension catalog with category filters and search
- Quick installation via Composer and Artisan import
- Status tracking of installed versions
- Re-importing static assets and migrations
- Copyable terminal command for manual installation

## Installation

```bash
composer require laveroadmin/marketplace
php artisan admin:import marketplace
```
